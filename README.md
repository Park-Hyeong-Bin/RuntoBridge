# BridgeRunner 🏃‍♂️🌉
> **UE5 기반 3인칭 무한 런닝 액션 게임 (1인 개발 포트폴리오)**
> 뒤에서부터 실시간으로 무너지는 다리를 탈출하며 장애물을 회피하고 최고 기록을 갱신하는 게임입니다.

<br>

## 📌 1. 프로젝트 개요
* **개발 기간**: 2024.05.13 ~ 2024.05.22 (10일)
* **개발 인원**: 1인 (박형빈)
* **담당 역할**: 기획, C++ 코어 프레임워크 구현, 디버깅 및 트러블 슈팅
* **개발 목적**: Unreal Engine 5의 핵심 구조(`AActor`, `APawn`, `AGameModeBase`) 및 C++ 프레임워크 숙련도 향상
* **프로젝트 진행 보고서**: https://docs.google.com/document/d/1IOiyxNFeBlDytvnYK5hDf5-LezpYM3mGRR9jZhuxVyA/edit?usp=sharing
  
<br>

## 🛠 2. 사용 기술 (Tech Stack)
* **Unreal Engine 5.7**: 핵심 클래스 계층 구조 분석 및 게임플레이 프레임워크 설계
* **C++**: 무한 맵 생성 및 메모리 풀링 등 엔진 코어 시스템 구현
* **Niagara VFX**: 함정 오브젝트(불꽃 트랩) 파티클 이펙트 구현
* **JetBrains Rider**: C++ 개발 환경 구축 및 AI 추천 도구를 통한 생산성 최적화

<br>

## ⚙️ 3. 핵심 기능
* **무한 맵 & 메모리 풀링**: 실시간 다리 타일 스폰/디스폰 처리로 메모리 누수 및 오버헤드 방지
* **랜덤 오브젝트 배치**: 확률 데이터 기반으로 장애물, 함정, 코인을 무작위 배치하여 긴장감 유도
* **다중 사망 판정**: 장애물 충돌(후방 밀림), 불 트랩 접촉, 추락 시 즉각 Game Over 처리
* **데이터 로컬 저장**: 이동 거리 및 코인 획득 점수를 합산하여 로컬 최고 기록(SaveGame) 저장

<br>
